# Personal Space — персональная страница разработчика

Один экран о человеке за кодом: аватар, короткое описание, соцсети и email. React + TypeScript + Vite. Без серверной части и аналитики.

## Возможности

- Адаптивный тёмный интерфейс, орбитальная композиция и локальный 3D-аватар.
- Canvas-частицы с реакцией на указатель и лёгкий параллакс.
- Палитра команд: Ctrl/⌘ K, поиск, клавиатурная навигация Tab и Enter.
- Отключение анимаций в палитре и поддержка prefers-reduced-motion.
- Ссылки на произвольные соцсети, mailto и копирование email.
- Редактор профиля и экспорт JSON. UTC-часы.

## Настройка

Пока имя, аватар и описание демонстрационные. Личные ссылки и email намеренно пусты. Ненастроенная карточка открывает редактор вместо перехода на чужой аккаунт.

Откройте настройки кнопкой внизу справа или командой «Настроить профиль». Задайте имя, специализацию, описание, аватар, email и любые соцсети.

**«Сохранить» сохраняет только в текущем браузере (localStorage). Это не серверная админка.**

Для публикации данных всем посетителям:
1. В редакторе нажмите «Скачать profile.json».
2. Замените `public/profile.json` скачанным файлом.
3. При необходимости положите свою аватарку в `public/images/` и задайте путь `./images/avatar.png`.
4. Обновите начальный title в `index.html`. После загрузки профиля название вкладки обновляется автоматически.
5. Сделайте commit/push в main.

Если в вашем браузере осталась старая локальная версия, удалите ключ `dev-profile-v2` из localStorage или откройте сайт в приватном окне. Данные из localStorage имеют приоритет над публичным JSON.

Не размещайте в JSON пароли или токены. Все его данные публичны. Внешние ссылки разрешены только с http/https.

## Разработка

- `npm install`
- `npm run dev`
- `npm run build`
- `npx tsc --noEmit`

Шрифты Golos Text и JetBrains Mono загружаются с Google Fonts; предусмотрены системные fallback-шрифты. Аватар хранится локально.

## GitHub Pages

Workflow уже находится в `.github/workflows/deploy.yml`.

1. Загрузите проект вместе с папкой `.github` в GitHub-репозиторий, ветку `main`.
2. Settings → Pages → Build and deployment → Source → GitHub Actions.
3. Actions → Deploy portfolio to GitHub Pages → Run workflow, либо сделайте новый push в main.
4. Дождитесь успешного deployment. Ссылка появится в Settings → Pages.

Workflow собирает `dist` с относительным base (`--base=./`) и публикует официальными GitHub Actions. Поэтому сайт работает и в подпапке репозитория. Публикация ещё не выполнена: требуется ваш репозиторий и доступ владельца. Не передавайте пароли или персональные токены в переписке.
