# zentorno — personal card

Минималистичная сайт-визитка для GitHub Pages: 3D-аватар, короткое описание и контакты. Preact + TypeScript + Vite, без сервера, аналитики и публичной админки.

Страница пререндерится при сборке: текст и контакты приходят готовым HTML (~2 КБ), интерфейс оживает от 9 КБ скриптов, а Three.js и модель подгружаются отдельно.

## Настройка профиля

Все публичные данные находятся в [`public/profile.json`](public/profile.json). Изменяйте его только у себя в репозитории, затем сделайте commit и push — GitHub Pages опубликует новую версию.

- `name` — имя на странице;
- `role` и `bio` — короткая подпись;
- `avatar` — путь к фотографии, например `./images/my-photo.jpg`. В арке показывается 3D-рыцарь, а фото подставляется, если WebGL недоступен или модель не загрузилась;
- `email` — включает кнопку «Написать»;
- `socials` — список карточек: название, ссылка и подпись.

У Discord нет публичного профиля по нику, поэтому карточка без `url` копирует подпись (ник) в буфер обмена и стоит в конце списка. Чтобы она стала ссылкой, вставьте в поле `url` приглашение на свой сервер или прямую ссылку на профиль с числовым Discord ID. Для Telegram, Instagram и TikTok ссылки на `zentorno` уже добавлены.

Настроек на самом сайте нет: посетители не могут изменить профиль ни для всех, ни «сохранить» его у себя. Это статичный сайт: JSON встраивается в страницу при сборке, поэтому изменения появляются после публикации (commit и push).

Не добавляйте в JSON пароли, токены или другую приватную информацию — содержимое файла доступно всем посетителям.

## 3D-аватар

В арке показывается glTF-модель `public/models/knight.glb`. Модель начинает скачиваться сразу (preload), Three.js подгружается отдельным файлом после отрисовки страницы (`src/avatar/stage.ts`); если WebGL недоступен или файл не загрузился, остаётся фото из `profile.json`. Сцена рисует 30 кадров в секунду в покое и 60 при движении, снижает разрешение на слабых видеокартах и останавливается, когда арка вне экрана или вкладка скрыта.

Сейчас это модель, сгенерированная в Meshy по арту. Чтобы заменить её, скачайте GLB из Meshy, Tripo или любого редактора и выполните:

```bash
npm run avatar:import -- ~/Downloads/model.glb
```

Скрипт упростит сетку примерно до 80 тыс. треугольников, уберёт неиспользуемые карты металла и шероховатости, переведёт текстуры в WebP 1024 px и сожмёт геометрию (meshopt). Сайт сам развернёт модель боком, как на арте, отмасштабирует и впишет в арку.

## Локальный запуск

```bash
npm ci
npm run dev
```

Для проверки production-сборки (с пререндером):

```bash
npm run build
npm run preview
```

## GitHub Pages

В этой папке сейчас нет Git-репозитория, поэтому отправить изменения в GitHub отсюда нельзя. Когда папка будет инициализирована как репозиторий или открыта в клоне репозитория, обычный путь такой:

```bash
git add src/App.tsx src/index.css public/profile.json README.md
git commit -m "Refresh personal card"
git push
```

В GitHub включите Pages для ветки `main` (или настройте GitHub Actions, если в репозитории есть workflow публикации).
