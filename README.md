# Zentorno — portfolio

Одностраничное portfolio-сайт разработчика Zentorno: React, TypeScript, Vite, Tailwind CSS, Framer Motion и Lucide.

## Запуск

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

## Настройка профиля

Основной контент и список социальных ссылок находятся в `src/App.tsx`. GitHub уже указывает на `https://github.com/Zent0rn0`; остальные ссылки легко заменить на подтверждённые профили.
